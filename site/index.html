Optimized fork for native-text research papers

Same paper. Two parser paths. One run each.

This fork preserves Firecrawl PDF Inspector's standard path and adds a trusted research-paper path for controlled native-text sources such as arXiv. The optimized path skips redundant pre-extraction classification while keeping the normal extraction, layout, Markdown and quality-analysis core.
