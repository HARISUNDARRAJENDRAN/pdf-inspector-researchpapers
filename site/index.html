Optimized fork for native-text research papers

Research-paper parsing, without redundant work.

This fork keeps Firecrawl's general-purpose PDF Inspector intact and adds a trusted research-paper fast path for sources such as arXiv. The fast path skips pre-extraction classification work while preserving the normal extraction, layout, Markdown and quality-analysis pipeline.

Implementation comparison
Upstream-safe by default. Faster when the source is trusted.
Firecrawl standard path
General-purpose PDF handling
Best for arbitrary files where the application does not know what kind of PDF it has.
  • Classifies TextBased, Scanned, ImageBased or Mixed documents.
  • Performs detector sampling and font/encoding checks before normal extraction.
  • Preserves routing signals for OCR and unknown uploads.
  • Use for user uploads, old papers, scans and unknown sources.
Research-paper fast path
Trusted native-text ingestion
Best when the acquisition layer already establishes that the paper comes from a controlled native-text source such as arXiv.
  • Skips the redundant classification pass.
  • Runs the same extraction, layout and Markdown pipeline.
  • Keeps downstream quality and encoding signals.
  • Designed for high-throughput paper ingestion, study workspaces and paper-grounded LLM systems.
